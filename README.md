# FaceAttend – Face Recognition Attendance System

## Overview
FaceAttend is a Python-based attendance management system that uses facial recognition technology to automatically identify individuals and record attendance in real time.

## Features
- Real-time face detection
- Face recognition using webcam
- Automatic attendance recording
- Easy setup and execution
- Attendance data storage

## Technologies Used
- Python
- OpenCV
- NumPy
- Pandas
- Face Recognition

## Installation

### Windows
```bash
cd face-attendance
setup.bat
start.bat
```

### Linux/macOS
```bash
 cd .\face-attendance-1.2-add-files
chmod +x setup.sh start.sh
.\setup.bat
.\start.bat
```

- Educational institutions
